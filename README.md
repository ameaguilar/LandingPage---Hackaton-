# Landing Page - Tienda Deportiva

## Instrucciones del proyecto

### MISIÓN

Crear una landing page interactiva, que muestre los principales productos y servicios de una **tienda deportiva**. La plataforma online debe destacarse por:

- Tener un diseño atractivo.
- Facilitar la exploración del contenido mediante una interfaz intuitiva.
- Adaptarse visualmente a diferentes dispositivos.

### HERRAMIENTAS

Usarán las siguientes herramientas:

- **HTML (HyperText Markup Language):** Para crear y estructurar el contenido de páginas web.
- **Hojas de Estilo (CSS o Bootstrap):** Para controlar el aspecto y la presentación de un sitio web.
- **Animaciones con JavaScript:** Aplica animaciones, inserciones de los productos al carrito y transiciones de página para enfatizar ideas y hacerlas incluso más memorables.
- **Visual Studio Code:** Para desarrollo del proyecto que incluya todos los lenguajes.

### ENTREGA Y EVALUACIÓN

Al finalizar el Hackathon (en este mismo día) deberán entrar a Canvas a subir la liga de GitHub de su proyecto y ahí entrará el instructor para evaluarlos de acuerdo con los siguientes aspectos:

- Creatividad e innovación.
- Funcionalidad.
- Diseño y experiencia de usuario.
- Estructura del código HTML.
- Calidad del código CSS.
- Calidad del código JS.

### EQUIPOS

Cada equipo estará conformado por **3 o 4 participantes asignados de forma aleatoria**.

## Descripción de la página

El proyecto corresponde a una **landing page de una tienda deportiva**. Su objetivo es presentar de forma visual los productos de la tienda y permitir que el usuario recorra el contenido de manera sencilla desde una sola página.

La página está organizada alrededor de contenido deportivo, promociones y productos. Dentro de los archivos entregados se encuentran recursos para mostrar:

- Una sección principal o **hero**.
- Un banner de **promoción**.
- Contenido relacionado con **Running**.
- Contenido relacionado con **Training**.
- Contenido relacionado con **Lifestyle**.
- Productos deportivos como camisetas, chaquetas, conjuntos, hoodies, leggings, maletas, rompevientos, shorts, tenis, tops y accesorios.
- El logotipo de la tienda.

## Funcionalidades contempladas en el proyecto

El proyecto contempla diferentes funciones para hacer la landing page interactiva:

- Mostrar los productos y secciones principales de la tienda.
- Navegar por el contenido de la landing page.
- Utilizar animaciones y efectos mediante JavaScript.
- Agregar productos al carrito.
- Incluir una sección de newsletter.
- Adaptar visualmente la página a diferentes tamaños de pantalla.

## Estructura principal del proyecto

```text

├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── main.js
│   ├── animations.js
│   ├── cart.js
│   └── newsletter.js
├── images/

    └── recursos gráficos adicionales
```

### Archivos principales

- **index.html:** estructura principal de la landing page.
- **css/styles.css:** estilos y presentación visual de la página.
- **js/main.js:** lógica general del sitio.
- **js/animations.js:** animaciones y efectos visuales.
- **js/cart.js:** lógica relacionada con el carrito de productos.
- **js/newsletter.js:** lógica relacionada con la sección de newsletter.
- **images/ e img/:** imágenes utilizadas en la página.
